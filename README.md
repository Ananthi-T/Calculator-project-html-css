# Calculator-project-html-css
Calculator UI (HTML &amp; CSS) – A visually appealing calculator interface designed using HTML and CSS, showcasing modern UI design, styled buttons, and a clean layout for front-end portfolio purposes.
---

## 📘 Project Overview
This project is a **clean and visually appealing calculator interface** built using **HTML and CSS**.  
It demonstrates front-end design skills, organized layout, and styled buttons for a simple calculator.  

The calculator UI includes:

- Styled buttons for numbers and operations  
- Display area for input and results  
- Functional layout with organized grid design  

> **Note:** This project focuses on **UI design only** and does not include JavaScript functionality.

---

## 🎨 Features
- Modern, dark-themed calculator interface  
- Rounded and evenly spaced buttons  
- Separate styling for functional buttons (`AC`, `%`, `+`, `−`, `×`, `÷`, `=`)  
- Double-width zero button for better usability  
- Clean, portfolio-ready UI design  

---

## 🧰 Tools Used
- **HTML5** – Structure of the calculator  
- **CSS3** – Styling, layout, and button design
